## 〇、用户 4 项决策（本次修订依据）

| # | 决策 | 含义 |
|---|------|------|
| 1 | 硬编码 CSS 先抽离作为**基底 CSS** | 现有 identity.js 里所有硬编码 rgba 颜色，先抽成一个「基底风格」CSS（含全部默认值），作为兜底/默认层 |
| 2 | 全域引用 `--ff-theme-*` | UI 组件颜色统一改为 `var(--ff-theme-xxx, 基底值)`——基底值兜底，主题变量覆盖 |

## 一、总体架构（修订后）

```
主题层 = 基底风格（默认） + 覆盖风格（可选，可叠加）

┌─────────────────────────────────────────────────┐
│  基底风格 styles/base.css（新文件）              │
│  :root { --ff-theme-bg: ...; --ff-theme-accent: ...; }    ← 现值 = 流萤默认色（从 identity.js 抽离）
│  所有 UI 组件原始样式（背景/边框/文字/按钮）        │
│  引用方式：背景 var(--ff-theme-bg, 垫底值)          │
└─────────────────────────────────────────────────┘
            ▲ 被覆盖
┌─────────────────────────────────────────────────┐
│  动态风格 styles/theme-<hash>.css（运行时生成）    │
│  :root { --ff-theme-bg: 从壁纸提取; ... }          │
│  只写变量覆盖，不写组件样式（复用基底的选择器）      │
└─────────────────────────────────────────────────┘
```

- **基底 CSS**：一个静态文件（或 build 注入段），把现有 identity.js 的硬编码颜色全部改写成 `var(--ff-theme-xxx, 原值)`，`--ff-theme-*` 变量定义与组件样式同处。
- **动态风格**：壁纸取色后只改写 `--ff-theme-*` 变量的值（`root.style.setProperty`），组件样式保持基底定义、自动跟随变量变化——**一套 UI，多套可换肤的变量集**。
- **命名空间**：全部变量统一 `--ff-theme-*` 前缀（bg / accent / text / border 4 类，见七）；与现有 `--dsw-alias-*`（tokens.js 品牌令牌）**并存**——`--ff-theme-*` 管「壁纸联动皮肤」，`--dsw-alias-*` 管「固定品牌色」。

## 二、修改目标

- **问题描述**：当前主题色固定流萤绿，壁纸换图后 UI 颜色与画面不协调。
- **期望效果**：图片壁纸切换时，UI 主题色（面板/按钮/文字/边框）随壁纸主色平滑联动；视频壁纸保持最后一张图片的主题不变。
- **成功标准**：
  1. 切换图片壁纸 → UI 色随主色变化（肉眼可见、可截图对比）；
  2. 切换视频壁纸 → UI 色不变（保持上一张图片的主题）；
  3. 无壁纸/取色失败 → 回落基底流萤色，UI 正常；
  4. 同一张图片切回 → 不重复计算（缓存命中，零延迟）。

## 四、基底 CSS 抽离方案（决策 1 + 2 落地）

### 4.1 现状（已核实）

identity.js L78-100 的面板 CSS 全部是**硬编码 rgba**，如：
```css
.ff-bg-panel { background: rgba(10,18,32,0.9); border: 1px solid rgba(125,255,158,0.35); }
.ff-bg-seg.active { background: rgba(0,255,135,0.24); color: #7dff9e; }
```

### 4.2 抽离步骤

**Step 1**：identity.js 的样式字符串改为引用变量，原值作为 `var()` 的 fallback：
```css
.ff-bg-panel {
  background: var(--ff-theme-panel-bg, rgba(10,18,32,0.9));
  border-color: var(--ff-theme-border, rgba(125,255,158,0.35));
}
.ff-bg-seg.active {
  background: var(--ff-theme-accent-dim, rgba(0,255,135,0.24));
  color: var(--ff-theme-accent, #7dff9e);
}
```

**Step 2**：把「变量定义 + fallback 值」集中为基底风格定义（仍放 identity.js 或单独注入段，作为 `styles/base` 的等价物）：
```css
:root {
  --ff-theme-bg: rgba(6,10,20,0.30);          /* 原 --dsw-alias-bg-base 值 */
  --ff-theme-panel-bg: rgba(10,18,32,0.9);    /* 原 .ff-bg-panel background */
  --ff-theme-accent: #7dff9e;                 /* 原品牌绿 */
  --ff-theme-accent-dim: rgba(0,255,135,0.24);
  --ff-theme-text: #eafff3;
  --ff-theme-text-dim: rgba(170,230,200,0.7);
  --ff-theme-border: rgba(125,255,158,0.35);
}
```

**Step 3**：`ffBuildTheme` 生成同名变量覆盖值（壁纸取色后 setProperty 覆盖）。

> 关键：**组件样式只写一遍**（基底选择器 + var 引用），换肤只改 `:root` 变量值——这才是「一组风格 CSS 文件夹」的根基：多套风格 = 多套 `:root { --ff-theme-* }` 块。

### 4.3 透明度问题（修订解决）

原方案 `ffBuildTheme` 输出**不透明** `rgb()`（bg 亮度 12%），会盖掉壁纸透出。修订：
- `--ff-theme-panel-bg` / `--ff-theme-bg` 等背景变量，动态值统一转 **rgba(色相, 亮度, 0.85~0.92 参照原透明度)**——用 `ffHslToRgb` + 原透明度映射，保留「半透明 + backdrop-filter blur」的通透层次；
- 取色 `--ff-theme-accent` 等前景色保持不透明（醒目）。

## 五、调用点（决策 3 后修订：视频不切换 CSS）

### 5.1 唯一入口（推荐收口）

方案原 2 处调用点改为**在 `render(item)`（wallpaper.js L92）内统一收口**——所有切换路径（init / 手动选择 / pickType / 上一张下一张 / 随机轮换 / 定时切换）天然经过 render，一处改动全覆盖：

```js
function render(item) {
  ...
  ffUpdateThemeFromWallpaper(item);  // 新增：内部已判断 kind !== "image" 直接返回（视频不切换）
}
```

`ffUpdateThemeFromWallpaper` 内：
```js
if (!item || item.kind !== "image") return;   // 视频：不触发、不动主题（沿用图片最后一套）
```

### 5.2 备选（不改 render，只按原方案 2 处）

- `initWallpaper()` → `render(startItem)` 后；
- `addWallpaper()` → 两个 showByIndex 后。
- **不推荐**：随机轮换/定时切换/上一张下一张等路径会漏掉（partial 切换无主题联动）。

**结论：采 5.1 收口方案。**

## 六、命名规范（决策 4 落地：一组风格 CSS 文件夹）

### 6.1 变量命名空间 `--ff-theme-*`

| 变量 | 语义 | 动态来源 | 基底默认 |
|------|------|----------|----------|
| `--ff-theme-bg` | 根背景（最透明层） | 主色 hsl 亮度12%+饱和40% | rgba(6,10,20,0.30) |
| `--ff-theme-panel-bg` | 面板背景 | 主色 + 透明度 0.9 | rgba(10,18,32,0.9) |
| `--ff-theme-bg-soft` / `--ff-theme-bg-layer` | 层次背景 | 主色亮度 18/24% | 原 layer-1/2 值 |
| `--ff-theme-accent` | 强调色（按钮/高亮） | 次主色高饱和 | #7dff9e |
| `--ff-theme-accent-dim` | 强调淡底 | accent 降透明 | rgba(0,255,135,0.24) |
| `--ff-theme-text` | 主文字 | 主色高亮度 92% | #eafff3 |
| `--ff-theme-text-dim` | 次文字 | 亮度 65% | rgba(170,230,200,0.7) |
| `--ff-theme-border` | 边框 | 主色亮度 32% | rgba(125,255,158,0.35) |

> 全部组件只认这 8 个变量 + 基底 fallback；**新增风格 = 新增一套变量值，不新增组件 CSS**。

### 6.2 风格 CSS 文件组织（预设）

```
styles/                        ← 与 docs/ 平级的仓库顶层目录（或 assets/ 下）
├── base.css                   ← 基底：变量定义 + fallback（= 现有 identity.js 抽离）
├── theme-aurora.css           ← 预定风格 1（示例：极光色，手动可选）
├── theme-sunset.css           ← 预定风格 2（示例：日落色，手动可选）
└── theme-dynamic-<hash>.css   ← 壁纸动态取色生成的风格（运行时生成/内存，可选落盘）
```

- 基底 `base.css` 必选，其余预定风格**可选扩展**（本期不做，只留目录约定 + 变量契约）；
- 壁纸动态取色：运行时直接 `setProperty` 覆盖变量（不落盘 css 文件，省 IO；如要持久化可落 styles/ 由 build 注入/服务端静态提供，本期不做）；
- 手动风格切换（future）：`document.documentElement` 上挂/换风格 class 或直接换变量集。

### 6.3 语义

- `--ff-theme-*`：壁纸联动皮肤（本期实现）；
- `--dsw-alias-*`：品牌固定色（tokens.js，不动）。

## 七、风险与缓解（修订后）

| 风险 | 可能性 | 影响 | 缓解 |
|------|--------|------|------|
| 性能退化（图片首次取色） | 低 | 100px canvas 毫秒级 | 降采样 + 缓存 |
| 并发取色回跳（快速切图） | 中 | 后完成先应用 | **序号守卫**：`ffUpdateThemeFromWallpaper` 内 `seq++`，仅应用最新 seq 结果 |
| 透明度破坏（面板不透/全透） | 中 | 观感 | 变量带原透明度映射（4.3） |
| 命名冲突 | 低 | — | 已核实 ff* 无冲突 |
| 视频切主题色突变 | 高（原方案） | 颜色跳动 | **决策 3：视频直接 return，不切换**（消除） |
| 老浏览器 `img.decode()` | 低 | 不取色 | catch 回落（onload 兼容写法可选） |
| 冷启动无图 | 低 | 用基底 | `ffBuildTheme(null)` → null，不覆盖 |

**边界条件（≥3 条）**

1. null/空列表：`ffUpdateThemeFromWallpaper(null)` return；colors 空 → theme null 不 setProperty ✅
2. 加载失败/跨域：catch 静默，保持基底 ✅
3. 快速连切多图：seq 守卫丢弃过期结果 ✅（新增）
4. 视频→视频：无取色触发，主题保持 ✅（决策 3）
5. 无壁纸：基底色兜底 ✅
