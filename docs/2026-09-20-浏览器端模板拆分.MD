# 浏览器端模板拆分（lib/client.template.js 2147 行 → lib/client-parts/ 17 片段）

> 状态：已完成｜2026-09-20（版本保持 1.0.2，不升版）

## 背景

`lib/client.template.js`（2147 行）是浏览器端主题源码**单文件 bundle**：`window.__ModuleLoader__.load({ id, factory })` 注册，factory 闭包内无 import/export，素材以 `/*__FIREFLY_*_START__*/.../*__FIREFLY_*_END__*/` 占位符由 build.cjs 注入。与 `lib/index.js` 的 ESM 拆分不同（无导出面、单闭包共享变量），不能机械按顶层块切——采用**按职责段拆片段 + build.cjs 按序拼接**方案。

## 目录结构（最终定稿）

按职责分 5 个子目录 + 根入口，文件名去掉数字前缀（顺序由 build.cjs PART_ORDER 唯一权威表达）：

```
lib/client-parts/
├── apply.js                    # 入口（ctx.effect 全量装配，类似 lib/index.js 角色）
├── foundation/                 # 基础支撑：最先声明，被所有片段引用
│   ├── loader.js               # ← 原 00-head：注释头 + ModuleLoader.load + factory 开头 + module/exports
│   ├── constants.js            # ← 原 01-constants：THEME_ID 与 localStorage 键常量

│   └── assets.js               # ← 原 04-assets：素材占位符（WALLPAPERS/GIF_DATA/MUSIC/DEFAULT_COVER/EMOTES）

│   ├── boot.js                 # ← 原 06-boot：开屏变身动画
│   ├── wallpaper.js            # ← 原 07-wallpaper：壁纸切换/随机/面板/选择器
```

拼接顺序（build.cjs PART_ORDER）：foundation 全部 → scenes 全部 → sound 全部 → secrets（emotes 先、egg 后，保持原 13→14 顺序）→ toolbar → apply。

## 关键决策

1. **拼接顺序即行为保证**：浏览器 bundle 单闭包共享变量，只要按原序拼接，产物与拆分前**逐字节一致**——用 `scripts/split-template.py` 的 `verify()` 断言（parts 拼接 == 原文件 sha256 一致）作为铁律。
2. **片段边界 = 职责段注释行**：每片段起点=该段 `═══` 注释行，终点=下一段注释行的前一行，行区间连续无重叠。
3. **旧模板文件删除**（进 .trash 可恢复）：避免「两份实现并存、改一处漏一处」；build.cjs 读 parts 拼接，README 目录结构与构建说明同步。
4. **目录重设计（2026-09-20 二稿）**：初稿 `lib/parts/00-NN-*.js` 平铺命名（数字前缀 + 语义名混排、music-parts/music-player 重叠、egg/dock 模糊）改为按职责 5 子目录语义命名；文件名去数字前缀，顺序由 PART_ORDER 数组唯一权威（数组内注释标注分组）。改目录/改名后 build 产物与改名基线（npm 包内 client.js，sha 9af95043）**逐字节一致**。
