# 浏览器端模板拆分（lib/client.template.js 2147 行 → lib/parts/ 16 片段）

> 状态：已完成｜2026-09-20（版本保持 1.0.2，不升版）

## 背景

`lib/client.template.js`（2147 行）是浏览器端主题源码**单文件 bundle**：`window.__ModuleLoader__.load({ id, factory })` 注册，factory 闭包内无 import/export，素材以 `/*__FIREFLY_*_START__*/.../*__FIREFLY_*_END__*/` 占位符由 build.cjs 注入。与 `lib/index.js` 的 ESM 拆分不同（无导出面、单闭包共享变量），不能机械按顶层块切——采用**按职责段拆片段 + build.cjs 按序拼接**方案。

## 拆分方案

`scripts/split-template.py`：按固定行区间把原文件切成 16 个片段到 `lib/parts/`，每片段以换行结尾；`build.cjs` 按 `PART_ORDER` 顺序 `readFileSync + join("")` 拼回完整模板，随后按原逻辑注入素材清单。

## 关键决策

1. **拼接顺序即行为保证**：浏览器 bundle 单闭包共享变量，只要按原序拼接，产物与拆分前**逐字节一致**——用 `scripts/split-template.py` 的 `verify()` 断言（parts 拼接 == 原文件 sha256 一致）作为铁律。
2. **片段边界 = 职责段注释行**：每片段起点=该段 `═══` 注释行，终点=下一段注释行的前一行，行区间连续无重叠。
3. **旧模板文件删除**（进 .trash 可恢复）：避免「两份实现并存、改一处漏一处」；build.cjs 读 parts 拼接，README 目录结构与构建说明同步。
