> 状态：方案已确认，执行中
> 依据：用户提供知更鸟（《崩坏：星穹铁道》角色）官方 6 色配色表，要求「作为项目基底 CSS，所有涉及的配色都用上，既指色号，也指页面」

## 二、用户决策

| # | 决策 | 含义 |
|---|------|------|
| 1 | 作为项目基底 CSS | 替换当前「流萤萤火绿」主题，成为项目唯一基底（非新增主题） |
| 2 | 所有配色都用上 | 6 个色号全部映射进页面（文字/强调/按钮/背景/高亮），不只换 1-2 个主色 |
| 3 | 既指色号也指页面 | 设计令牌（--dsw-*）与基底变量（--ff-theme-*）同步替换，页面整体呈现知更鸟色调 |
| 4 | 流萤配色暂存备份 | **不是删除替换**——原流萤值以注释块备份在 identity.js / tokens.js，当前不启用；仅用于 `preview/theme-swatch.html` 对照页展示（流萤 vs 知更鸟双栏），便于日后恢复/切换 |

## 三、当前颜色体系（改造前）

- **基底变量** `lib/client-parts/scenes/identity.js` 的 `--ff-theme-*`（8 个）：深空蓝黑背景 × 萤火绿强调（125,255,158）× 莹白文字
- **设计令牌** `lib/client-parts/foundation/tokens.js` 的 `TOKENS`（`--dsw-*`，约 50 个）：全流萤绿系（#7dff9e / #00ff87 / #00e676）
- 硬编码遮罩 `rgba(4,8,18,...)` 深空蓝黑渐变（壁纸可读性遮罩，保留）

## 四、映射方案（6 色全用）

| 知更鸟色 | 色号 | 映射用途 |
|----------|------|----------|
| 肤色 | `#FDF0FA` | 主文字（替代莹白 #eafff3）、对比按钮文字 |
| 发色 | `#C8B8D8` | 次级文字/淡紫银（替代薄荷灰 #a9c9b9）、渐变文字 |
| 瞳色 | `#6B8E5A` | 主强调色（替代萤火绿 #7dff9e，保留绿系基因）、品牌主色 |
| 服装-灰白 | `#F0F0F5` | 背景亮部/边框亮部、浮层底色 |
| 服装-紫色 | `#8A6D9B` | 按钮填充/选中态/装饰紫（替代 #00e676） |
| 点缀-金色 | `#D4AF37` | 高亮/辉光/强调点缀（替代 #ffd93b 部分场景） |

### 变量级映射细节

- `--ff-theme-bg` 系列（背景深空蓝黑）：保留深色基底（页面深色阅读环境不变），但微调向紫调靠拢（知更鸟背景是淡紫白，但作为深色主题保留深空背景、文字层用知更鸟浅色系）
- `--ff-theme-accent`（主强调）: `125,255,158` → `107,142,90`（瞳色 #6B8E5A）
- `--ff-theme-text`（主文字）: `234,255,243` → `253,240,250`（肤色 #FDF0FA）
- `--ff-theme-text-dim`（次级）: `170,230,200` → `200,184,216`（发色 #C8B8D8）
- `--ff-theme-border`（边框）: `125,255,158` → `212,175,55`（点缀金 #D4AF37）——金色辉光边框，替代绿框
- `--ff-theme-accent-soft`（软强调）: `0,230,118` → `138,109,155`（礼服紫 #8A6D9B）
- `--ff-theme-bg-soft`/`--ff-theme-bg-layer`（背景层）: 微调紫调

### TOKENS（--dsw-*）映射要点

- 品牌主色 brand-primary/text：`#7dff9e` → `#6B8E5A`（瞳色）
- 按钮主填充 button-primary-fill：`#00e676` → `#8A6D9B`（礼服紫），hover 提亮
- 按钮对比文字 contrast-fill：`#eafff3` → `#FDF0FA`（肤色）
- 文字 primary/secondary/tertiary：莹白/薄荷灰 → 肤色/发色/灰白系
- 状态 success：`#00ff87` → `#6B8E5A`（瞳色绿）；warn 保留金黄调 → `#D4AF37`（点缀金）
- 边框 l1-l4：绿 → 金（#D4AF37 低透明度）
- 交互 hover/active：绿 0.09/0.16 → 紫 0.09/0.16（礼服紫）
- scrollbar：绿 → 金
- 组件特化 sidebar 激活/高亮：绿 → 紫
- skeleton/tip/markdown 强调：绿 → 紫/金

## 五、影响面与风险

| 项 | 说明 |

| 影响文件 | `lib/client-parts/scenes/identity.js`（8 个变量）、`lib/client-parts/foundation/tokens.js`（~50 个令牌）、`lib/client.js`（build 产物） |
