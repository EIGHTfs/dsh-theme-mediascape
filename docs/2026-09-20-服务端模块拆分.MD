# 1.0.2 服务端模块拆分（lib/index.js 526 行 → 6 模块）

> 状态：已完成｜2026-09-20

## 背景

1.0.1 交付后 `lib/index.js` 累积到 526 行，职责混杂：路径推导、labels 映射读写、在线下载器（断点续传）、HTTP 处理器（删除/列表/上传）、路由注册全部挤在一个文件里。按「文件夹是职责单位、index 只写引用」原则拆分为 6 个模块。

## 拆分方案

| 模块 | 行数 | 职责 |
|---|---|---|
| `lib/config.js` | 53 | 常量与配置：MIME 表、白名单目录、上传扩展名、上传上限计算（statfs 动态） |
| `lib/paths.js` | 25 | 路径推导：`wallpaperDir()` / `onlineDir()` / labels 文件路径 |
| `lib/labels.js` | 29 | labels 映射读写（hash 主键 → 展示文件名）+ 模块级缓存 |
| `lib/online.js` | 188 | 在线资源下载（hash 主键配置、后台静默、断点续传 .part、SHA-1 校验） |
| `lib/handlers.js` | 185 | HTTP 处理器：`handleDelete` / `handleList` / `handleUpload` |
| `lib/index.js` | 83 | 入口：`registerAssets`（注册前缀路由）+ `apply`（DSH 调用） |

`package.json` `main` 指向不变（`lib/index.js`），对外导出面不变：`apply`、`registerAssets` 两个导出均保留，DSH 侧调用零改动。

## 关键决策

1. **labelMap 归 labels.js 私有**：拆分初版把 `let labelMap` 留在 paths.js 导出、labels.js `import` 后赋值，触发 ESM「Assignment to constant variable」（import 绑定只读）。修复：labelMap 改为 labels.js 模块内 `let`，paths.js 只做路径推导——可变状态归属读写它的模块。
2. **ONLINE_SOURCES_FILE 归 online.js**：读取路径只需 ROOT，与在线下载器同模块。
3. **index.js 只保留注册+入口**：路由分发（上传/删除/列表/静态）全部委托 handlers.js，config/paths 只被具体模块 import。
